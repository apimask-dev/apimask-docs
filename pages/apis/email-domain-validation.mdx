# Email, Domain, and Website Utilities API

Use these APIs for signup validation, website monitoring, SEO checks, security audits,
and operational tooling. The headline endpoint is
[email validation](/api/email-validation): it flags addresses at 10,000+
disposable domains and suggests corrections for typos like `gmail.con`.

Every endpoint here costs 1 unit per call and is included in every plan,
including Free. For lists, use the
[Bulk Email Verification API](/api/bulk-email-verification).

## Endpoints

| Endpoint | Method | Docs |
|---|---|---|
| `/v1/utility/email/validate` | `POST` | [Email Validation API](/api/email-validation) |
| `/v1/utility/dns/analyze` | `POST` | [DNS Analyzer API](/api/dns-analyzer) |
| `/v1/utility/ssl/check` | `POST` | [SSL Checker API](/api/ssl-checker) |
| `/v1/utility/url/safety` | `POST` | [URL Safety Checker API](/api/url-safety-checker) |
| `/v1/utility/security-headers/analyze` | `POST` | [Security Headers Analyzer API](/api/security-headers-analyzer) |
| `/v1/utility/robots/analyze` | `POST` | [Robots.txt Analyzer API](/api/robots-txt-analyzer) |
| `/v1/utility/sitemap/validate` | `POST` | [Sitemap Validator API](/api/sitemap-validator) |
| `/v1/utility/cors/check` | `POST` | [CORS Checker API](/api/cors-checker) |
