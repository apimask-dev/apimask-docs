# Regex Explainer API

Explain a regular expression in plain English. Use it in developer education,
debugging tools, code review assistants, and validation UI.

> **Pro plan.** This is an AI endpoint: it needs the [Pro plan](/pricing) and
> costs 20 units per call. Free and Starter keys get `403 FORBIDDEN_PRODUCT`.
> Test keys on Pro return a fixed sample response at no cost.

## Endpoint

```http
POST /v1/dev/regex/explain
```

## Request body

| Field | Type | Required | Description |
|---|---|---:|---|
| `pattern` | `string` | Yes | Regular expression pattern to explain. |

## Example request

```bash
curl --request POST \
  --url https://api.apimask.dev/v1/dev/regex/explain \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $APIMASK_API_KEY" \
  --data '{"pattern":"^[A-Z][a-z]+$"}'
```

## Example response

```json
{
  "success": true,
  "data": {
    "explanation": "Matches one capital letter followed by one or more lowercase letters.",
    "breakdown": [
      { "token": "^", "meaning": "Start of string" },
      { "token": "[A-Z]", "meaning": "One uppercase letter" }
    ]
  },
  "error": null,
  "meta": {}
}
```
