# Stacktrace Analyzer API

Analyze stacktraces and error messages for developer tools, CI systems, support
workflows, and coding assistants.

> **Pro plan.** This is an AI endpoint: it needs the [Pro plan](/pricing) and
> costs 20 units per call. Free and Starter keys get `403 FORBIDDEN_PRODUCT`.
> Test keys on Pro return a fixed sample response at no cost.

## Endpoint

```http
POST /v1/dev/stacktrace
```

## Request body

| Field | Type | Required | Description |
|---|---|---:|---|
| `stacktrace` | `string` | Yes | Raw stacktrace or error message. |
| `language` | `string` | No | Programming language, if known. |
| `framework` | `string` | No | Framework, if known. |

## Example request

```bash
curl --request POST \
  --url https://api.apimask.dev/v1/dev/stacktrace \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $APIMASK_API_KEY" \
  --data '{"stacktrace":"TypeError: Cannot read properties of undefined","language":"javascript","framework":"nextjs"}'
```

## Example response

```json
{
  "success": true,
  "data": {
    "error_type": "TypeError",
    "root_cause": "Code attempted to access a property on an undefined value.",
    "fix_suggestion": "Check that the object exists before reading from it.",
    "documentation_links": ["https://developer.mozilla.org/"]
  },
  "error": null,
  "meta": {}
}
```
