# Developer Utilities API

Developer utility endpoints for CI automation, code assistants, and backend
tools. The data utilities run on every plan, including Free, and cost 1 unit per
call. The five AI endpoints (regex generate and explain, stacktrace, README,
changelog) need the [Pro plan](/pricing) and cost 20 units per call.

## Endpoints

| Endpoint | Method | Plan | Docs |
|---|---|---|---|
| `/v1/dev/email/validate` | `POST` | All | [Email Validation API](/api/email-validation) |
| `/v1/dev/regex/generate` | `POST` | Pro | [Regex Generator API](/api/regex-generator) |
| `/v1/dev/regex/explain` | `POST` | Pro | [Regex Explainer API](/api/regex-explainer) |
| `/v1/dev/stacktrace` | `POST` | Pro | [Stacktrace Analyzer API](/api/stacktrace-analyzer) |
| `/v1/dev/readme` | `POST` | Pro | [README Generator API](/api/readme-generator) |
| `/v1/dev/changelog` | `POST` | Pro | [Changelog Generator API](/api/changelog-generator) |
| `/v1/dev/data/json/format` | `POST` | All | [JSON Formatter API](/api/json-formatter) |
| `/v1/dev/data/base64/encode` | `POST` | All | [Base64 Encode/Decode API](/api/base64-encoder-decoder) |
| `/v1/dev/data/base64/decode` | `POST` | All | [Base64 Encode/Decode API](/api/base64-encoder-decoder) |
| `/v1/dev/data/hash` | `POST` | All | [Hash Generator API](/api/hash-generator) |
| `/v1/dev/data/id/generate` | `POST` | All | [UUID/ULID Generator API](/api/id-generator) |
| `/v1/dev/data/url/parse` | `POST` | All | [URL Parser API](/api/url-parser) |

## Base URL

Every endpoint is served from one host:

```http
https://api.apimask.dev
```

## Authentication

```http
Authorization: Bearer apim_live_...
Content-Type: application/json
```
