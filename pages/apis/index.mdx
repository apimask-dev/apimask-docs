# ApiMask API Catalog

Every ApiMask endpoint, searchable. One [API key](/quickstart) covers every
endpoint your plan includes: everything on Free and Starter except the AI
endpoints, and everything on Pro. Endpoints marked **Pro plan** below are AI
endpoints.

## API families

These group related endpoints for reading. They are not separate subscriptions.

| Family | Best for | Plan |
|---|---|---|
| [Email & Domain Validation](/api/email-domain-validation) | Signup validation, disposable and typo detection, DNS, SSL, and security checks | All plans |
| [Bulk Email Verification](/api/bulk-email-verification) | CRM imports, list cleaning, CSV validation, domain health | All plans |
| [SEO Website Audit](/api/seo-website-audit) | SEO dashboards, agency reporting, launch QA | All plans (meta tags: Pro) |
| [Developer Utilities](/api/developer-utilities) | JSON, Base64, hashing, IDs, URL parsing | All plans (AI tools: Pro) |
| [QR Code Generator](/api/qr-code-generator-api) | URL, WiFi, vCard, email, SMS, and branded QR codes | All plans |
| [AI Content Generator](/api/ai-content-generator-api) | Summaries, rewrites, meta tags, captions, FAQs | Pro |

See [Pricing](/pricing) for what each call costs.
